# Glossary

> Last reviewed: 2026-09-04

- **Attempt** — one learner interaction with an exercise, including findings, hint use, retries, evaluation, and fix outcome.
- **Boss Review** — a reduced-scaffolding, multi-track challenge unlocked at a curriculum checkpoint.
- **Curriculum Completion** — progress through the curated learning path; it is not a claim of engineering skill.
- **Daily Mission** — one to three recommended tasks selected from prerequisites, weak topics, mastery, recency, and available time.
- **Deterministic evaluation** — explainable scoring based on exercise metadata and learner actions, without an LLM deciding the base result.
- **Exercise** — a versioned challenge containing requirements, code files, expected findings, hints, explanations, and a reference fix.
- **Finding** — a learner’s review observation tied to a file and line range, with category, diagnosis, impact, and possible fix.
- **Golden exercise** — a representative, carefully validated exercise used to prove the full product and scoring flow.
- **Mastery** — evidence-based performance quality for concepts or tracks, kept separate from completion.
- **Mission type** — a presentation frame such as Bug Hunt, Ship or Block?, Security Incident, or Boss Review.
- **Scaffolding** — structured guidance that decreases from beginner to advanced review modes.
- **Weak topic** — a concept prioritised for future practice after repeated misses, low-quality reasoning, or stale learning evidence.
